# Data Structures - Course Syllabus

## Course Information
- **Course Title:** Data Structures
- **Credit Hours:** 3 (2 hours lecture + 1 hour lab per week)
- **Prerequisites:** Basic programming knowledge (any language)

## Course Description
This course introduces fundamental data structures, their implementation in C++, and applications in solving computational problems. Students will develop skills in designing and modifying data structures and gain an awareness of their efficiency in terms of time and space.

## Course Objectives
By the end of this course, students will be able to:
1. Implement fundamental data structures using C++.
2. Design and adapt data structures to meet specific problem requirements.
3. Apply data structures to solve real-world computational tasks.
4. Recognize the importance of time and space complexities in data structure selection and usage.

## Weekly Schedule (14 Weeks)

| Week | Topics                              | Key Concepts                                   | Activities / Assignments                  |
|------|-------------------------------------|-----------------------------------------------|-------------------------------------------|
| 1    | C++ Basics: Syntax, Control Structures | Variables, I/O, loops, conditionals, functions | Simple coding exercises                    |
| 2    | C++ Arrays & OOP Intro                | Arrays, structs, classes, constructors         | Mini OOP exercise                           |
| 3    | Pointers & References                 | Pointer arithmetic, references, function pointers | Pointer-based problems                   |
| 4    | Dynamic Memory Management             | new/delete, shallow vs deep copy               | Dynamic array implementation                |
| 5    | Intro to Data Structures & Complexity | What are data structures? Big-O intuition      | Array vs linked list comparison             |
| 6    | Singly Linked List                    | Nodes, insert, delete, traversal               | Implement SLL                               |
| 7    | Doubly & Circular Linked List         | DLL operations, circular connections           | Implement DLL                               |
| 8    | Stacks                                | LIFO principle, array & linked list implementation | Undo feature simulation                  |
| 9    | Queues & Deques                       | FIFO, circular queue, deque                     | Process scheduling simulation               |
| 10   | Binary Trees                          | Tree representation, traversals                | Binary tree implementation                  |
| 11   | Binary Search Trees                   | Search, insert, delete                          | BST efficiency awareness                    |
| 12   | Heaps & Priority Queues               | Max-heap, min-heap, STL priority_queue          | Job scheduling example                      |
| 13   | Graph Basics                          | BFS, DFS awareness, adjacency list/matrix       | Simple graph exercise                        |
| 14   | Review & Mini Project                 | Real-world applications of data structures      | Mini-project presentations                  |
